# Impressed-paginas

Losse pagina's voor impressedpaper.com, gehost via GitHub Pages en ingeladen in WordPress/Elementor.

- `contentstudio/`: Create & Connect Contentstudio (snippet: `elementor-snippet.html`)
- `homepage/`: homepage "Twee paden, één deur" (snippet: `homepage/elementor-snippet.html`)

Plak de snippet in een HTML-blok in Elementor. De pagina laadt in een eigen afgeschermd blok (shadow DOM), zodat de stijl van het thema er niet aan komt.
